# OpenAI public submission checklist

Technical packaging is complete, but public-directory submission is intentionally not claimed complete.

## Completed

- Portable Agent Plugins manifest and Codex compatibility manifest
- Semantic version `0.3.1`
- Listing name and subtitle within 30 characters
- Three unique starter prompts within 128 characters
- Skills-only architecture with no unverified MCP dependency
- Valid skill frontmatter and portable paths
- 1024×1024 PNG logo and composer icon under 5 MiB
- Exact two-deliverable output contract
- JSON Schema and example scene specification
- Git-backed repository marketplace metadata
- Public website: `https://github.com/drecuk/SceneSpecBuilder`
- Public support page: `https://github.com/drecuk/SceneSpecBuilder/issues`
- Apache-2.0 license in the repository and installable package
- Public terms of service: `https://github.com/drecuk/SceneSpecBuilder/blob/main/TERMS.md`
- Clean release ZIP, checksum, inventory, and repeatable validation

Skills-only plugins do not need MCP review cases, a demo recording, or reviewer credentials under the current submission guidance.

## Publisher information still required

Do not upload for public review until the publisher provides and verifies:

- the selected verified individual or business identity;
- a privacy-policy URL based on confirmed collection, use, sharing, retention, and deletion practices;
- the final dashboard category and country availability;

The website and support fields use the public GitHub repository and its Issues page. The terms URL points to the published repository terms. The privacy field remains intentionally omitted until the publisher confirms accurate data practices; placeholders are not acceptable.

## Authorization still required

The user must explicitly authorize each external step: creating or pushing a GitHub repository, uploading a public draft, submitting for review, or publishing. Technical validation does not imply marketplace approval.
